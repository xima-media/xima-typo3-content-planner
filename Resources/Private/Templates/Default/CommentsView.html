Standalone counterpart to Default/Comments.html. That template is injected into a backend modal and driven by JavaScript; this one is the body of a complete document rendered for embedding, so every control here is a link. Keeping them separate means the modal path cannot regress when this view changes.
A link, not a toggle button — it navigates. aria-pressed would be ignored on it, so the state lives in the label instead of in an attribute. {filter.resolvedCount} Both of these leave the comment thread behind, so they must not replace the embedded frame with a backend page — they open in the top-level window.
